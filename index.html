The site I built in Web Technologies

Four pages, one stylesheet, one menu that is written once and inserted into every page by JavaScript. Nothing here is a template: every page is a file you can read from top to bottom.

What is on it

  • Quotes — sixteen lines I keep coming back to, each with who said it and where it comes from. The page opens on a random one, and the field hides the ones that do not match what you type.
  • Projects — six small things I could build, who each one is for, and the order I would build it in.
  • Machine — a box with a switch that turns itself off, and a reaction game that measures how fast you are.

How it is put together

The menu lives in nav.html. Every page has an empty <div id="nav"> and loads nav.js, which fetches the menu once and drops it in — so adding a page means editing one file, not four. Opened straight from the filesystem the browser refuses that request, so the script falls back to the same links written inside the script.

The stylesheet has one column of 60rem, one card style used by every quote, and two colours: a warm accent for the quotes, a blue one for links. The whole site works on a phone: the menu wraps, the pictures crop to a shorter band, and nothing scrolls sideways.
